# Data Reliability & Transaction Analysis

*Developed by- *RITU RAJ SINGH*

## Project Overview

This project focuses on data cleaning, Python-based data analysis, and Tableau dashboard visualization of transaction data.

The project follows an end-to-end data analytics workflow:

Excel Data Cleaning → Python Analysis → Tableau Dashboard → GitHub

## Tools Used

- Microsoft Excel
- Python
- Google Colab
- Pandas
- Tableau
- GitHub

## Project Workflow

### 1. Data Cleaning – Excel

The dataset was cleaned and validated using Microsoft Excel.

The cleaning process included:

- Checking duplicate records
- Handling blank values
- Cleaning text fields
- Standardizing date formats
- Formatting numerical fields
- Validating important data columns

The final cleaned dataset is provided in:

Cleaned_Dataset.xlsx

### 2. Python Analysis

The cleaned dataset was analyzed using Python in Google Colab.

Python was used for:

- Data inspection
- Data validation
- Summary analysis
- Transaction analysis
- Status analysis
- City-level analysis
- Source system analysis

Python code and outputs are available in:

Task_5_Python_Analysis.ipynb

The analysis results are available in:

Task_5_Python_Analysis.xlsx

### 3. Tableau Dashboard

A professional Tableau dashboard was created to visualize the analyzed transaction data.

The dashboard includes:

- Total Records KPI
- Total Amount KPI
- Status Analysis
- City Amount Analysis
- Source System Analysis
- Monthly Transaction Trend

The Tableau workbook is available in:

Task_5_Tableau_Dashboard.twbx

Dashboard preview:

Tableau_Dashboard.png

## Key Insights

The dashboard provides an interactive view of transaction records, total transaction amount, status distribution, city-wise amount, source-system analysis, and monthly transaction trends.
